# WorkoutPlan

- `app/` — веб-приложение. На локальной машине запустите PostgreSQL через `app/start-postgres-test.ps1`, затем `app/start.bat`. Приложение открывается на `http://127.0.0.1:18743/`.
- `WebCollector/` — сборщики, обработка данных и SQL-импорт. Инструкции по запуску находятся в `WebCollector/README.txt` и в папках сборщиков.

Локальная папка проекта: `E:\GoogleDrive\WorkoutPlan`. Диск `W:` указывает на `app/`. PostgreSQL слушает `127.0.0.1:15432`, основная база — `workoutplan`. Для запуска нужны локальные файлы PostgreSQL, драйвер и настройки подключения. Пароли, данные, выгрузки и резервные копии хранятся отдельно.
