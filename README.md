# ПланТренировок — локальная веб-версия

Запуск в Windows: дважды щёлкните `start.bat`, затем откройте http://127.0.0.1:18743 . Окно сервера должно оставаться открытым. Python 3.10+, внешних зависимостей нет. При ручном запуске `python server.py` без переменной PORT используется порт 18743.

Демонстрационные аккаунты: `user@demo.local`, `coach@demo.local`, `admin@demo.local`. При первом запуске сервер записывает случайный пароль демо-аккаунтов в `data/demo-password.txt`. На экране входа можно подставить адрес по роли.

Работают вход, права трёх ролей, добавление тренеров, библиотека упражнений, добавление тренировок клиенту, запись подходов и комментариев, просмотр результатов тренером. Сохранение — кнопкой после каждого упражнения. База хранится в `data/app.sqlite3`, сохраняется между перезапусками. Сессии при перезапуске сбрасываются. Внесена первая неделя из примеров; это не полный импорт месячного плана.

Медиа пока задаются HTTPS-ссылкой. Реальная техника выполнения должна предоставляться тренером: примеры без медиа явно помечены. Тренер может сохранить занятие как шаблон с описанием, галереей HTTPS-ссылок и обложкой, затем назначить копию клиенту. многонедельный редактор, календарные даты, редактирование будущих назначений, привязка новых клиентов, загрузка файлов, автоматическое сохранение, восстановление пароля и публичное развёртывание — следующие этапы. Отдых и разминочные результаты пока отдельно не записываются.

Это локальная ранняя версия. Перед публичным запуском нужны production-сервер, HTTPS, секреты окружения, отключение демонстрационных аккаунтов, лимиты попыток входа, срок действия сессий, защита/резервирование базы и полноценная проверка доступа. Не открывайте этот сервер напрямую в интернет.
