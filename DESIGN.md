# Интерфейс
Режим Operate: спокойный дневник тренировок, светлая бумажная поверхность, тёмно-зелёная навигация, лаймовый акцент действия. Чёткая табличная запись подходов, крупные доступные кнопки. Цвета: фон #f4f5ef, текст #172a24, акцент #c9ed85, вторичный #52635b. Системный шрифт для рабочих экранов, размеры 14/16/24/36px. На телефоне навигация переносится наверх, таблицы сохраняют компактность. Медиа не выдумываются: до загрузки показывается явное отсутствие материалов.
