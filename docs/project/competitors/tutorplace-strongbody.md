# TutorPlace — пример квиза для привлечения к тренировкам

Источник — https://strongbodyws6.tutorplace.ru/
Дата просмотра — 18 ноября 2026 года.
Категория — маркетинговый пример для нашего квиза. Пользователь выбрал этот сайт как ориентир.

В публичном тексте видны пошаговые вопросы, прогресс из 21 шага, выбор целей, опыта и условий тренировок, итоговый профиль и предложение перейти к программе. Фактическое изменение результата от ответов и условия оплаты не проверены. Квиз целиком в браузере не проходился.

Для «ПланТренировок» запланирован похожий сценарий привлечения с собственными вопросами и итоговым предложением. Вопросы и логику результата проработаем отдельно. Задача добавлена в маркетинговый раздел TODO приложения.

Для будущего разбора — последовательность вопросов, длина квиза, оформление вариантов, индикатор прохождения, связь ответов с итогом, переход к регистрации и измерение конверсии.
