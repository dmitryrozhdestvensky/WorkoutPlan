## Самостоятельная регистрация по приглашению

Пользователь сервиса может создать промокод в личном кабинете и самостоятельно передать его приглашённому. Для создания приглашения сервис не запрашивает имя, телефон или email приглашённого. При регистрации приглашённый сам заполняет форму. Код применяется по реферальной ссылке или вводится вручную.

Сервис связывает промокод с аккаунтом его владельца.
