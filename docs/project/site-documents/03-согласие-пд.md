# Согласие на обработку персональных данных для [конкретная цель]

Статус на 19.11.2026 — Универсальный шаблон. Требует выбора конкретной цели и заполнения полей перед использованием.

Редакция от [дата].

Я даю [наименование или ФИО оператора, адрес] согласие на обработку моих персональных данных для [одна конкретная цель, для которой требуется согласие].

Состав данных — [закрытый перечень полей]. Действия с данными — [действия, необходимые для этой цели]. Способ обработки — [фактический способ]. [При поручении обработки указать лицо, его адрес и операции, выполняемые по поручению.]

Согласие действует [конкретный срок или событие, позволяющее определить срок]. Я могу отозвать его, направив сообщение на [email] или по адресу [адрес]. Оператор прекратит обработку на основании этого согласия в порядке, установленном Федеральным законом № 152-ФЗ.

Текст для отдельного элемента формы — «Даю согласие на обработку персональных данных для [цель]». По ссылке рядом с отметкой доступен полный текст согласия этой редакции.
