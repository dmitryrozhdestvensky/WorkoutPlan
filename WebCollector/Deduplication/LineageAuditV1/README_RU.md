# ФитнесТренер — аудит происхождения совпадений V1

Модуль анализирует **1 824 пары** из предыдущего `fitness_merge_candidates_review.csv` и читает оригинальные поля `legacy_master` из действующей PostgreSQL. Он помогает отделить повторное включение исходных профилей из других источников в старую Excel-базу от **совпадения только ФИО**.

## Принцип безопасности

- Только чтение PostgreSQL (`default_transaction_read_only=on`), без создания, обновления, объединения, удаления карточек или записи в `fitness.merge_candidates`.
- Проверка доказательств `source lineage`: точного URL индивидуальной карточки в исходных полях `Страница тренера в источнике`, `Дополнительные источники — URL`, `URL источника`. URL общей страницы каталога **не считается** доказательством.
- Совпадение социальной ссылки, ФИО, клуба и города помечается как кандидат на ручную проверку личности, не как доказанное происхождение записи.
- Поле `Источник — название` лишь вспомогательное свидетельство, а не подтверждение идентичности.
- При отсутствии подтверждений связи **не создаются**. Социальные профили могут не принадлежать человеку, поэтому проверка обязательна.

## Установка

Распакуйте архив в `C:\WebCollector\Deduplication\LineageAuditV1` так, чтобы файл `audit_lineage.py` находился в этой папке.

В PowerShell:

```powershell
cd C:\WebCollector\Deduplication\LineageAuditV1
py -3.13 -m pip install -r .\requirements.txt
py -3.13 .\audit_lineage.py `
  --candidates "C:\WebCollector\Deduplication\Reports\fitness_merge_candidates_review.csv" `
  --output "C:\WebCollector\Deduplication\Reports\LineageAudit"
```

Используется pgpass Windows, пароль в скрипт и в чат отправлять не требуется. Подключение по умолчанию `127.0.0.1:15432`, база `workoutplan`, пользователь `workoutplan_test`.

## Результат

- `lineage_summary.json`: численные итоги по источникам и основаниям сопоставления;
- `lineage_candidates_detailed.csv`: все пары с проверенными признаками происхождения;
- `lineage_ambiguous_names.csv`: неоднозначные имена, в том числе один профиль Legacy Master ↔ два профиля DDX;
- `lineage_exact_urls.csv`: точные URL индивидуальных анкет, если обнаружены;
- `lineage_social_review.csv`: пары с общим социальным аккаунтом для дополнительной проверки.

**Не запускайте `--write-candidates` в старом модуле до разбора отчёта.** Новая программа не принимает такой параметр.
