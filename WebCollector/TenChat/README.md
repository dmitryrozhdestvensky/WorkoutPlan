# TenChat Collector V7 — Windows

Сбор **публичных карточек** TenChat через Playwright и объединение с базой **215 тренеров**.

## Что изменилось с V6

- Включены 3 категории: `trener-po-fitnesu`, `instruktor-po-fitnesu`, `instruktor-po-yoge` (последние две подлежат проверке наличия каталога на каждой странице).
- 100 ранее проверенных городов используются как исходный список. Новые города обнаруживаются по ссылкам на страницах. Возможность найти более 100 городов зависит от навигации TenChat.
- SQLite `collection_state.sqlite3`: прогресс сохраняется **после каждой страницы**, можно остановить `Ctrl+C` и продолжить.
- CSV с анкетами `tenchat_trainers_v7.csv`; журнал страниц `tenchat_pages_v7.csv`.
- Excel объединяется по нормализованному TenChat URL, существующие строки и ссылки не удаляются.
- Ограниченная частота запросов и предел страниц; при HTTP 403/429 или проверке доступа прекращает работу, не обходит ограничения.

## Запуск

Распакуйте в **новую папку**, например `C:\TenChatCollectorV7` (не поверх V6). Запустите `START_V7_WINDOWS.bat`.

Либо в PowerShell:

```powershell
cd C:\TenChatCollectorV7
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe collect_tenchat_v7.py --max-pages 250
.\.venv\Scripts\python.exe merge_excel_v7.py
```

При последующих запусках используйте **последний результат Excel** как основу: перед повторным `merge_excel_v7.py` сохраните копию текущего `fitness_trainers_merged_v7.xlsx` под именем `fitness_trainers_base_215.xlsx`, иначе экспорт будет начинаться с начальных 215 строк. Дубликаты в CSV не добавятся повторно.

Чтобы обработать следующую порцию страниц:

```powershell
.\.venv\Scripts\python.exe collect_tenchat_v7.py --max-pages 250
.\.venv\Scripts\python.exe merge_excel_v7.py
```

Чтобы повторно попробовать только ошибочные страницы: `--retry-errors`.

## Важные ограничения

- Включённые профессии — отдельно существующие публичные каталоги, **они не доказывают личность и профессию каждого пользователя**. `404`/другая страница не принимается за корректный каталог.
- Страницы разных городов могут возвращать одинаковые анкеты. Итоговая цель 500+ **не гарантирована**.
- Статус «Найдена ссылка в каталоге» не означает проверку владения профилем.
- Уважайте условия сайта и применимые правила работы с персональными данными. Не используйте собранные данные для нежелательных рассылок.
- Комплект проверен на синтаксис Python и наличие файлов, **живой обход 250 страниц не выполнялся**.
