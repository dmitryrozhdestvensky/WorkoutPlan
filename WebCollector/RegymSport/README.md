# RegymSport Collector V1

Собирает открытые персональные анкеты фитнес-тренеров сайта https://regymsport.ru/trenery/ и дополняет основную базу 386 тренеров.

## Установка на Windows (PowerShell)

Распакуйте в `C:\RegymSportCollector`. Уже установленные глобально браузеры Playwright могут использоваться повторно.

```powershell
cd C:\RegymSportCollector
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium
```

## Тест (первые 5 тренеров)

```powershell
.\.venv\Scripts\python.exe collect_regymsport.py --max-profiles 5 --show-browser
```

Посмотрите `regymsport_trainers.csv`. Для полного сбора:

```powershell
.\.venv\Scripts\python.exe collect_regymsport.py --show-browser
.\.venv\Scripts\python.exe merge_regymsport.py
```

**Результат:** `fitness_trainers_merged_regymsport.xlsx`.

- `regymsport_checkpoint.json` сохраняет уже собранные анкеты после каждого профиля. Повторный запуск продолжает сбор.
- `regymsport_errors.csv` — ошибки обхода.
- `regymsport_trainers.csv` — все найденные персональные страницы, ссылки и дополнительные сведения.
- `Импорт RegymSport` — журнал добавления и совпадений.
- `Источники профилей` — точные URL, откуда получена информация.
- `Проверить совпадения` — совпадения ФИО+города, которые нельзя автоматически считать одним человеком.
- `Сводка RegymSport` — актуальные показатели нового импорта.

Если после теста хотите выполнить повторный полный сбор с чистого листа, используйте `--fresh`. Без `--fresh` анкеты из теста сохранятся, и полный обход продолжит с 6-го профиля.

**Важно:** скрипт собирает только общедоступную информацию и не обходит авторизацию или защиту сайта. Личный VK засчитывается только при явной подписи вроде «Тренер во ВКонтакте». Корпоративные соцсети в шапке/подвале сайта не присваиваются тренеру. Не используйте найденные данные для спама; учитывайте применимые требования к персональным данным и рекламным сообщениям.

При изменении разметки сайта потребуется уточнение CSS/DOM-селекторов. Сайт полностью не тестировался из среды разработки, итоговое количество может отличаться.
