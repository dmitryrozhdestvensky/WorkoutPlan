World Class Collector V1.5 — API-first
=====================================

Что изменилось:
- Вместо кнопки «Показать ещё» использует подтверждённый диагностикой GET /api/trainers.
- В ответе API читает meta.pagination.pageCount и total, автоматически обходит страницы.
- Повторные запросы при HTTP 429/5xx и временных ошибках.
- Проверяет, что ID из API совпадает со ссылками уже собранного каталога. Если проверка не проходит, НОВЫЕ ссылки не записываются.
- Прежние анкеты и SQLite сохраняет; до начала делает резервные копии.
- Не меняет PostgreSQL и общую базу приложения.
- Уже сохранённые профили пропускает; ошибочные и новые повторяет.

УСТАНОВКА:
1. Закройте запущенный сборщик.
2. Сохраните резервную копию C:\WebCollector\WorldClass\collect_worldclass.py.
3. Из этого архива скопируйте ТОЛЬКО collect_worldclass.py в C:\WebCollector\WorldClass\ с заменой.
4. Не переносите и не удаляйте CSV, SQLite, Backups.

ЭТАП 1: быстро получить каталог URL (НЕ открывать все профили):
cd C:\WebCollector\WorldClass
.\.venv\Scripts\python.exe collect_worldclass.py --discover-only --api-max-pages 500 --delay 1.5

Убедитесь, что строка «API каталог: ok» и число заявленных total выглядят разумно.

ЭТАП 2: собрать детали новых анкет и повторить ошибки:
.\.venv\Scripts\python.exe collect_worldclass.py --skip-api --max-profiles 5000 --delay 1.5

Можно сразу выполнить сбор за один запуск (без этапа 1):
.\.venv\Scripts\python.exe collect_worldclass.py --api-max-pages 500 --max-profiles 5000 --delay 1.5

Зависимости: те же, что у работающего V1.4 (playwright, установленный Chromium).

ВАЖНО:
- Проверка API ID основана на совпадении с URL ранее собранных карточек. Если появится файл worldclass_api_id_check.json, остановитесь и пришлите его.
- Если доступ к API завершится ошибкой, собранное до этого сохраняется, в SQLite отмечается partial.
- Не запускайте два экземпляра сборщика одновременно.
- Пользуйтесь разумным интервалом; учитывайте условия использования сайта.
