WORLD CLASS COLLECTOR V1.7.1 — исправление таймаута API
========================================================

Причина предыдущей ошибки:
В браузерном fetch был установлен таймаут 45 секунд. При медленном ответе
World Class запрос отменялся AbortController, после чего API проходил
4 неудачные попытки. В V1.7.1 ожидание увеличено до 120 секунд.
Навигация к каталогу теперь ждёт commit, а не domcontentloaded.

Установка:
1. Сделайте дополнительную копию текущего скрипта.
2. Скопируйте WorldClass_Collector_V1_7_1.py в C:\WebCollector\WorldClass\
3. Запускайте новый файл из той же рабочей папки. Не помещайте его в подпапку:
   пути к SQLite/CSV зависят от расположения скрипта.

Команда:
cd C:\WebCollector\WorldClass
py -3.13 .\WorldClass_Collector_V1_7_1.py --show-browser --discover-only

Важно:
- Существующие 1 580 анкет и SQLite не удаляются.
- Перед запуском создаётся резервная копия.
- --discover-only обновляет карточки из API и не открывает индивидуальные страницы.
- PostgreSQL не затрагивается.

Если повторится таймаут:
Не запускайте многократно. Пришлите полный лог.
